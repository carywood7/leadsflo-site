# LeadsFlo — Niche Landing Page Standard

## Purpose

Use this checklist for every new LeadsFlo industry landing page.
Inspect the latest approved niche pages before implementation.
Do not rebuild each page as a static generic template.

## Required visual system

- Premium, modern, non-AI-looking layout with industry-specific colors.
- Preserve the official LeadsFlo typography and brand identity.
- Create an industry-specific animated logo accent when appropriate.
- Use the same refined logo in header and footer.
- Readable navigation, approximately 16px on desktop.
- Mobile-friendly navigation with accessible touch targets.
- Distinctive hero visual or interactive animation.
- Industry-specific real photography or approved illustrations.
- Meaningful alt text, responsive layouts and optimized image sizes.
- No invented client projects, metrics, testimonials or guarantees.

## Required interactions

- Continuous scrolling services/platforms marquee.
- High-contrast, readable marquee labels with hover pause.
- Interactive service cards with hover, focus and click/tap behavior.
- Dynamic content panel updated by card selection.
- Interactive lead-generation or sales journey.
- Journey stages update on pointer hover and keyboard focus.
- Click/tap support remains available for mobile.
- FAQs expand on hover for mouse users.
- Native click/tap and keyboard access remain functional.
- Interactive scenario calculator with working input controls.
- Clearly label calculator results as hypothetical, not forecasts.
- Respect prefers-reduced-motion.
- Visible focus indicators and semantic interactive controls.

## Required sections

1. Header, niche logo treatment and readable navigation.
2. Hero with real buyer pain point, clear offer and primary CTA.
3. Animated services/platforms marquee.
4. Niche-specific introduction and pain points.
5. Four or more service/capability cards.
6. Dynamic service or campaign preview.
7. Interactive lead-to-booking workflow.
8. Industry-specific visual/photo section.
9. Lead qualification / buyer fit explanation.
10. Working calculator where commercially relevant.
11. FAQs with hover and mobile support.
12. Related SEO article/resource cards.
13. Strong closing CTA.
14. Premium footer with matching animated logo, links and CTA.

## SEO and measurement

- One clear H1, unique title and meta description.
- Correct canonical URL and relevant structured data.
- Existing GA4 ID G-QE382W17N6, loaded exactly once.
- Shared conversion-click script.
- Do not count calendar CTA clicks as confirmed appointments.
- Add links to published related articles; avoid dead placeholders.
- Integrate with Insights, Industries and sitemap after approval.
- Never invent search volume, CPL, conversion rate or client results.

## Release process

1. Start from clean main and create a feature branch.
2. Build landing page and review desktop/mobile screenshots.
3. Refine interactivity, photography, logo, footer and accessibility.
4. Obtain landing page approval.
5. Build relevant supporting SEO articles.
6. Connect article cards, internal links, Industries and Insights.
7. Update sitemap with canonical public pages.
8. Run Astro production build, link and SEO audit.
9. Commit, merge and deploy only after approval.

## HVAC V7 approved refinements — mandatory for future niches

The HVAC page was approved on November 4, 2026.
These are requirements for future niche landing pages,
not optional features to add after the first review.

### Header and branding
- [ ] Desktop navigation is prominent and readable: approximately 18px.
- [ ] Header uses the approved LeadsFlo logo with niche-matched colors.
- [ ] Industry-specific logo icon or accent, with polished alignment.
- [ ] Animated airflow/current or an appropriate niche motion treatment.
- [ ] Identical logo treatment in the footer, not a generic replacement.
- [ ] Mobile navigation remains accessible and avoids crowding.

### Hero and visual content
- [ ] Strong niche-specific headline and commercial buyer pain points.
- [ ] Hero has a distinctive interactive or animated visual.
- [ ] Keep the HVAC example's spinning equipment fan as its reference.
- [ ] Use genuine industry photos in relevant editorial sections.
- [ ] Use optimized local assets with meaningful alt text.
- [ ] Clearly label stock examples; never imply they are client work.
- [ ] Do not put unnecessary geography in visible hero labels.
- [ ] Retain US SEO targeting when relevant in metadata and content.

### Scrolling capabilities section
- [ ] Christmas Lighting-style premium scrolling marquee.
- [ ] High-contrast background and separate cream/light service cards.
- [ ] Large readable labels, approximately 16px.
- [ ] Industry-matched icon color, card borders, rounded corners.
- [ ] Continuous seamless motion from right to left.
- [ ] Pause on mouse hover and focus.
- [ ] Respect reduced-motion settings.
- [ ] No pale, low-contrast ticker as the default design.

### Interactive sections
- [ ] Service cards respond to hover, focus, click and keyboard.
- [ ] Relevant service details change without requiring a click.
- [ ] Lead journey switches content on mouse hover.
- [ ] Mobile tap functionality remains operational.
- [ ] FAQs open on hover; native details still work on tap and keyboard.
- [ ] Calculator uses real JavaScript and labeled hypothetical inputs.
- [ ] Distinct hover/focus states, responsive layouts and contrast.

### Footer
- [ ] Same brand animation and styling as the header.
- [ ] Multi-column service, company and contact navigation.
- [ ] Relevant booking or consultation CTA.
- [ ] Privacy and terms links.
- [ ] Working links and responsive mobile stacking.

### SEO, tracking and workflow
- [ ] Unique H1, meta description, canonical and relevant schema.
- [ ] Existing GA4 property loaded exactly once.
- [ ] Track booking CTA clicks; never mistake them for appointments.
- [ ] Connect 3-5 substantial, distinct supporting SEO articles.
- [ ] Link articles from landing cards, Insights and Industries.
- [ ] Update sitemap only after landing page approval.
- [ ] Run a clean production build and audit all new routes.
- [ ] Do not modify existing niche pages without approval.
- [ ] Do not deploy until the user approves the release.
- [ ] Use one copy/pasteable terminal code block; never ZIP downloads.
